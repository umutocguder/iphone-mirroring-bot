# iphone-bot Kuralları ve Geliştirme Standartları

Bu proje, macOS iPhone Mirroring penceresi üzerinden ekran okuma (Vision OCR) ve CoreGraphics olayları ile kampanya butonlarına otomatik tıklayan bir Python otomasyon botudur.

## Geliştirme Standartları
- Dil: Python 3.10+ (macOS Vision Framework, CoreGraphics, PyObjC)
- Değişiklikler yapıldığında mutlaka bu dizindeki `WORKLOG.md` güncellenmeli ve kişisel GitHub reposuna (`origin main`) otomatik pushlanmalıdır.
